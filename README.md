# Sizhe Chen

Source for [sizhe-chen.github.io](https://sizhe-chen.github.io/), a static
academic website containing a biography, invited talks, publications, people,
academic service, awards, and miscellaneous interests.

The minimalist visual structure is adapted from
[Chawin Sitawarin's academic-site template](https://github.com/chawins/chawins.github.io),
whose README permits reuse for academic websites.

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.

The `.nojekyll` file tells GitHub Pages to publish the HTML, CSS, and assets
directly without processing the legacy Jekyll source files that remain in the
repository.
